# روان‌یار V5 — نسخه تجاری Production Hardened

نسخه V5 بر پایه نسخه تجاری V4 (فازهای ۱ تا ۳) ساخته شده است. این نسخه هسته فروش، اشتراک، محصولات، فایل، نسخه‌بندی، تیکت، اعلان، گزارش و مدیریت را حفظ کرده و چند ایراد مهم Production را اصلاح کرده است.

## امکانات مهم

- PostgreSQL و مدل داده تجاری
- داشبورد نقش‌محور برای کاربر شخصی، روان‌شناس/مشاور، کلینیک/مرکز، مدرسه/مرکز آموزشی و مدیر سامانه
- منوی متفاوت و اقدام‌محور برای هر نقش
- مسیرهای ارزیابی، برنامه، منابع، گزارش و پیگیری به‌جای نمایش مستقیم همه محصولات
- کاربران و نقش‌های تخصصی
- پلن‌های عادی، نقره‌ای و طلایی
- محصولات و دسته‌بندی‌ها
- فایل‌های چندگانه و نسخه‌بندی
- کنترل دسترسی بر اساس پلن + وضعیت و تاریخ انقضای اشتراک
- سفارش، پرداخت و کد تخفیف
- تمدید صحیح اشتراک فعال
- فاکتور پس از پرداخت موفق
- تیکت و اعلان
- Audit Log مدیران
- دانلود محافظت‌شده فایل
- Streaming/Range برای فایل‌های بزرگ
- Rate Limit ورود
- Session TTL
- Security Headers و CSP
- محدودیت حجم درخواست و آپلود
- حذف فایل‌های فیزیکی هنگام حذف محصول
- endpoint سلامت `/health`
- Dockerfile و Docker Compose

## اجرای محلی

پیش‌نیاز: Node.js 22+ و PostgreSQL 17+

```bash
npm install
npm start
```

سپس:

`http://localhost:3000`

سلامت سرویس:

`http://localhost:3000/health`

**قبل از هرگونه استقرار عمومی، رمز را تغییر دهید.**

## پرداخت

حالت محلی `mock` است. برای پرداخت واقعی بله، `PAYMENT_MODE=real`، `PAYMENT_GATEWAY=bale` و سه مقدار `BALE_BOT_TOKEN`، `BALE_BOT_USERNAME` و `BALE_PAYMENT_PROVIDER_TOKEN` را تنظیم کنید. برنامه درخواست پول را به چت بلهٔ متصل‌شدهٔ کاربر می‌فرستد؛ سرویس جداگانهٔ `bale-bot` تأیید پیش‌پرداخت و پرداخت موفق را پردازش می‌کند. فعال‌شدن اشتراک فقط پس از آپدیت `SuccessfulPayment` انجام می‌شود.

## Docker

```bash
docker compose up -d --build
```

قبل از اجرا رمزهای placeholder در `docker-compose.yml` را تغییر دهید.

## استقرار واقعی

قبل از انتشار عمومی موارد `PRODUCTION_CHECKLIST.md` و `DEPLOYMENT.md` را کامل کنید؛ به‌خصوص HTTPS، Backup/Restore، درگاه واقعی، secrets، Object Storage در صورت نیاز، اسکن فایل و تست نفوذ.
